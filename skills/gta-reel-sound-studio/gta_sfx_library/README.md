# GTA SFX library

263 sound effects, each cut to its own file (`sfx/<id>.flac`, peak -1 dBFS), listed with tags, length and peak time in `library.json`.

Used by the **gta-reel-sound-studio** skill (this folder sits inside it). Set the plan's `"sfx_dir"` to this folder's path; cues name sounds by `id`.

Search it: `python3 ../scripts/list_sounds.py . --tag impact --no-music` or `--find "cash register"`.

## Rights

- `earshot` sounds are generated by earshot from public-domain recordings and are free to use commercially, without credit.
- The TechKeyFi videos describe their sounds as copyright free.
- Warrior SFX sounds tagged `music` are clips of commercial songs: platforms can mute, demonetise or block reels that use them. Keep them short, and leave them out of monetised or brand uploads.
- Sounds tagged `explicit` contain swearing or crude meme audio.
- These files were cut from videos you downloaded: keep the repository private and the library for your own editing.
